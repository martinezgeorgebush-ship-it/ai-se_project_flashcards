# Flashcard App

My first project in TripleTen's AI-Assisted Software
Engineering program. It includes decks of flashcards,
each of which can be viewed in a carousel.

## Features

- Flashcards to memorize topics
- Multiple decks to browse
- Open deck view to browse and manage all cards in a single deck
- Fully responsive design for mobile, tablet, and desktop screens

## Technologies used

- HTML
- CSS
- JavaScript
